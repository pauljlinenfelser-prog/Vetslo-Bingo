# VETSLO BINGO — ERROR LIST
#
# This is the master list the game pulls from. Edit it right on GitHub:
# click the pencil icon, make your change, then click Commit changes.
# The game picks up the change within a few minutes. No need to touch index.html.
#
# How it works:
#   - Put one error message per line, under [common], [uncommon] or [rare].
#   - Start a line with ! to show it as a yellow VETRO warning instead of a pink error.
#   - Lines starting with # are notes and get ignored. Blank lines are fine.
#   - To make an error more or less rare, move its line to a different group.
#   - Type the message exactly how it should appear on the card.
#
# Each card gets 14 common, 7 uncommon and 3 rare.
# Cards people already have never change. New errors show up on new cards
# and in the "Share an error" list right away.
